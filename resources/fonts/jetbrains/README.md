# JetBrains Mono

The face of the code on this site: JetBrains Mono, Copyright 2020 The
JetBrains Mono Project Authors (https://github.com/JetBrains/JetBrainsMono),
under the SIL Open Font License 1.1 (`JetBrainsMono-LICENSE.txt`).

`JetBrainsMono-Roman.woff2` and `JetBrainsMono-Italic.woff2` are the
variable fonts (weights 100 to 800) of Fontsource,
`@fontsource-variable/jetbrains-mono` 5.3.0, Latin subset
(`jetbrains-mono-latin-wght-normal.woff2` and `-italic.woff2`), unchanged.
The site turns off their ligatures, so that code shows as it is typed.
