# IBM Plex Sans

The face of this site: IBM Plex Sans, by Mike Abbink and Bold Monday for
IBM, Copyright 2019 IBM Corp., under the SIL Open Font License 1.1
(`IBMPlexSans-LICENSE.txt`).

`IBMPlexSans-Roman.woff2` and `IBMPlexSans-Italic.woff2` are the variable
fonts (weights 100 to 700) of Fontsource, `@fontsource-variable/ibm-plex-sans`
5.3.0, Latin subset (`ibm-plex-sans-latin-wght-normal.woff2` and
`-italic.woff2`), unchanged. The Latin subset covers ASCII and Latin-1, all
that the Markdown sources may hold.
